# AURORA Software Architecture

AURORA uses a modular architecture.

## Core Modules

- Perception: image processing, object detection and tracking.
- Autonomy: mission planning and decision making.
- Navigation: navigation-related algorithms and interfaces.
- UAV: flight controller communication and telemetry.
- Common: shared utilities and data structures.

## Simulation

Gazebo integration is maintained in `simulation/gazebo/`.

## Testing

Automated tests are maintained in `tests/`.

## Configuration

Project configuration files are maintained in `configs/`.
